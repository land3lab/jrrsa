# 양성이 — 코드 리뷰용 정리

위반건축물 양성화 사전검토 PWA. 주소나 건축물대장 파일을 넣으면 ① 위반 여부 ② 특조법 대상·가능 여부 ③ 양성화 전후 수치 ④ 전후 3D를 바로 보여준다.

- 배포: Vercel 프로젝트 `jrrsa-yangseongi` (Root Directory = `yangseongi`)
- 공식 주소: `https://yangseongi.land3lab.com` (보조: `https://jrrsa-yangseongi.vercel.app`)
- 브랜치: 작업 브랜치 `ccr-44401bfb-o5pmn7` → `main`에 직접 푸시 (fast-forward)
- **GitHub PR: 없음.** 모든 커밋이 리뷰 없이 `main`에 들어갔다. 리뷰가 필요하면 `0383cff..main` 범위로 보면 된다.
- 비밀값: 이 문서에는 API 키·비밀번호를 적지 않았다. 키 위치는 "남은 문제 §보안"을 볼 것.

## 3. 데이터 흐름

```
주소 입력 ─┐
지도 클릭 ─┼─▶ /api/ys-lookup ─▶ applyLookup() ─▶ S.P (프로젝트 상태) ─▶ compute() ─▶ analyze(P) ─▶ render()
대장 파일 ─▶ readFile() ─▶ parseRegister() ─▶ mergeParsed() ─┘                                     (카드·지도·3D·시트)
```

### 3-1. `/api/ys-lookup` (서버)

1. **주소 해석**: 브이월드 검색 → 카카오 → 도로명주소 API → 내장 표(서울 25개 구 코드 + 관악·동작 일부 법정동) 순서. 키가 없는 단계는 건너뛴다.
2. **병렬 조회**: 건축HUB `getBrTitleInfo / getBrRecapTitleInfo / getBrFlrOulnInfo / getBrJijiguInfo / getBrExposPubuseAreaInfo` + 브이월드 필지(`LP_PA_CBND_BUBUN`, PNU)·용도지역(`LT_C_UQ111`).
3. **보강**: 필지를 못 얻으면 브이월드 지오코더 좌표로 그 점의 필지를 다시 조회. 마지막으로 필지 BOX 안의 `LT_C_SPBD` 건물 중 **중심이 필지 안에 있는 가장 큰 것**을 실제 외곽선으로 반환.
4. 주 건축물 선택: 부속이 아닌 것 중 연면적 최대. 다세대 전유면적은 동·호별 합산 후 최대값.

```js
// 브이월드는 등록 도메인과 함께 호출해야 함 — VWORLD_DOMAIN 없으면 요청 Host 사용
if (!process.env.VWORLD_DOMAIN && req.headers && req.headers.host)
  VW_DOMAIN = `https://${req.headers["x-forwarded-host"] || req.headers.host}`;
```

## 4. 건축물대장 자동 입력 로직

### 4-1. 텍스트 추출 (`upload.js`)
- PDF: pdf.js 텍스트 레이어(최대 6쪽, y좌표로 줄 구분). 글자가 60자 미만이면 스캔본으로 보고 3쪽까지 렌더링 후 OCR.
- 비밀번호: `task.onPassword`에서 화면 입력창을 띄움(틀리면 재입력). 비밀번호는 저장하지 않음.
- 이미지: 2400px로 줄이고 흑백·대비 강화 후 Tesseract(kor+eng).
- 쪽별 원문을 보관하고, 각 숫자 값이 몇 쪽에 있는지(`pageOf`) 찾아 출처 비교표에 표시.

### 4-2. 항목 추출 (`parse.js`)
순서가 중요하다.

1. **표 형식 우선** `tableValues()`: 정부24 PDF는 "대지면적 연면적 …" 라벨 줄 다음 줄에 값이 같은 순서로 온다. 라벨을 단위(㎡/%/m)별로 묶고 다음 줄의 같은 단위 숫자를 순서대로 배정.
2. **라벨 바로 뒤 숫자**(사진 OCR 대비)로 빈 항목만 채움.
3. **위반 내역**: `위반건축물 표기[내역: 4층 25㎡/ 옥상 24㎡ 조립식패널조 …]` 형식을 먼저 읽고(있으면 이것이 최우선), 없으면 `무단증축 ○○㎡` 같은 변동사항 문구.
   - 옥상·옥탑 → `roofAdd`, N층 → `floorAdd`(층 일부 증축), 1층 → `sideAdd`, 필로티·주차장 → `piloti`, 발코니 → `balcony`
4. **교차 검증 후 의심 값 버림** (`out.dropped`에 사유 기록):
   - 건축면적 > 대지면적, 연면적 < 건축면적 → 버림
   - 건폐율·용적률은 면적으로 다시 계산해 1.5%p / 3%p 넘게 다르면 계산값으로 교체
   - 높이가 건폐율·용적률과 같은 값이거나 층수×(1.8~6)m 범위 밖 → 버림
   - 연면적 = 대지면적, 용적률산정 연면적 = 건축면적(2층 이상) → 버림

### 4-3. 병합 규칙 (`app.js` `mergeParsed` / `applyLookup`)
- 새 파일 묶음은 이전 주소·샘플 값과 섞이지 않게 **새 프로젝트로 시작**(같은 주소면 위치만 유지).
- 대장에서 주소를 읽으면 그 주소로 `/api/ys-lookup`을 호출(`keepLegal: true`).
- **수치는 건축HUB 우선**, 첨부 값은 건축HUB가 비어 있는 항목만 채움. **위반 표기·위반 내역은 첨부 대장에서**.
- 건축HUB 주용도가 '단독주택'이라도 기타용도·층별 용도에 '다가구'가 있거나 가구 수 ≥ 2면 다가구로 분류.
- **표기 미검출 ≠ 위반 없음**: 첨부에서 위반 표기·내역을 못 찾으면 `violationsUnknown = true`('확인 필요'). 표기만 있고 면적이 없으면 '위반 내용 입력 후 판정'.

```js
P.noMarkDetected = !f.violationMarked && !res.violations.length;
P.violationsUnknown = P.noMarkDetected && !P.legal.violationMarked && !(P.violations || []).length;
```

## 5. 판정 로직 (`engine.js` `analyze(P)`)

법령 수치는 2026-11-08 국가법령정보센터 원문과 대조했다(`laws.js`).

**① 위반 여부**: 대장 '위반건축물' 표기 또는 위반 내역 1건 이상. 위반 유형별로 건축면적·연면적·용적률 연면적·높이·층·세대수에 더해 "현황" 수치를 만든다.

**② 특조법 대상** (법률 제21820호 제2·3조)
- 2023.12.31 완공, 주거용 연면적 ≥ 50%, 용도: 다세대(세대당 전용 85㎡ 이하) / 단독(165㎡, 조례로 ~330㎡) / 다가구(660㎡) / 주택으로 쓰던 근생
- 제외 구역 9종(제3조②③)은 체크리스트 입력
```js
const legalOverCap = typeOk && cat !== "dasedae" && before.tot > capValue + 1e-6; // 적법 부분만으로 초과
const targetStatus = !isViolation ? "none" : !isTarget || legalOverCap ? "no" : capOk ? "yes" : "partial";
```

**사용승인 기준** (제6조①): 대지 권리, 접도 2m(도로 3m 미만은 건축선 후퇴 확인), 일조 현저한 지장(개정 제61조 기준을 보수적으로 적용), 구조·방화, 세대 증가 시 방화·피난·소방, 체납. 실패 항목이 일조·체납·접도뿐이면 '조건부 가능'.

**③ 기준별 존치 한도 — 두 경로**
- A. 특조법: 건폐율·용적률은 "건축법 및 관계 법률에도 불구하고"로 **적용 배제**. 한도는 규모 상한과 일조.
- B. 건축법 추인: 조례 건폐율·용적률·일조를 모두 충족.
  - 건폐율: `maxArch - 대장 건축면적`만큼 수평 증축 존치
  - 용적률: `maxFar - 대장 용적률 연면적`
  - 일조: 옥상 증축부를 북측에서 `(필요 이격 - 현재 이격) × 건물 동서 폭`만큼 감축
- 각 경로에서 존치 면적이 가장 작은 기준이 "가장 제한적인 기준", `위반면적 - 존치`가 최소 보완 규모. 특조법 대상이면 A, 아니면 B를 권장하고, 감축은 옥상 → 부속 → 층 일부 → 수평 → 발코니 순으로 배분.

**일조**: 개정 건축법 제61조①(2026.11.12 시행): 높이 10m 이하 1.5m, 10~17m 5m, 17m 초과 h/2. 정북 이격은 실제 외곽선이 있으면 "건물 최북단 − 필지 최북단"(축 정렬 경계상자 기준)으로 자동 측정.

**이행강제금**: 시가표준액(㎡) × 50% × 위반면적 × 비율(건폐율 80 / 용적률 90 / 무허가 100 / 무신고 70%), 용도변경·세대 증설은 시행령 별표 15의 10%, 60㎡ 이하 주거 1/2. 특조법 과태료 = 5회분 − 기납부.

## 7. 남은 문제

### 보안
1. **공공데이터포털 서비스 키가 과거 커밋에 남아 있음**: `yangseongi/api/_util.js`에서는 제거하고 Vercel 환경변수 `DATA_GO_KR_KEY`만 사용. `realestate-app/api/_util.js`에는 아직 기본값이 있음(그 앱의 배포 위치 확인 후 제거). 키는 계정 단위라 재발급 시 모든 프로그램을 바꿔야 하므로 일정을 잡아 일괄 교체 권장.
2. `/api/ys-lookup`·`/api/ys-config`에 사용량 제한·출처 제한이 없다(Vercel Firewall 규칙 권장). 호출 절약: 성공 응답은 Vercel CDN에 하루 캐시(`s-maxage=86400, stale-while-revalidate=604800`), 필지별 인스턴스 메모리 캐시 6시간, 건축HUB는 표제부 1회 + 필요할 때만 추가 호출(보통 조회당 1~2회).
3. 브이월드 지도 키는 설계상 브라우저에 공개된다(도메인 제한 전제).
4. 서버 함수의 `VW_DOMAIN`과 `vwErrors`가 모듈 전역 변수라, 같은 인스턴스에서 동시 요청이 오면 섞일 수 있다. 요청 단위 변수로 바꿔야 한다.

### 정확도·법령
5. 특조법 **시행령은 입법예고 단계**(2026.9.30~11.9). 신고기간·소방 예외·서식은 공포본으로 다시 확인할 것. 원문 공고는 직접 읽지 못했고 법제처 목록·기사로만 확인했다.
6. 건폐율·용적률 조례값은 **서울만** 내장. 다른 지역은 국토계획법 시행령 법정 상한을 기본값으로 쓴다.
7. 특조법 경로의 일조는 "현저한 지장"이라는 심의 판단을 개정 제61조 수치로 근사했다.
8. 정북 이격과 증축·철거 위치는 축 정렬 경계상자 기준의 근사다. 위반 부분은 실제 형상이 아니라 단순 상자로 그린다.
9. 이행강제금은 시가표준액 기본값(750,000원/㎡)을 가정한 추정이다. 무허가/무신고 구분도 유형별 고정값.
10. 대장 파싱은 휴리스틱이다. 실제 정부24 PDF 원본, 집합건축물 표제부·전유부로는 아직 시험하지 않았다.
11. 키 없이 쓰는 주소 해석 표는 서울 25개 구 + 관악·동작 일부 동만 있다(그 외는 주소검색 팝업이나 브이월드 필요).

### 코드·운영
12. **PR·리뷰 없이 main 직접 푸시.** 저장소에 테스트·린트·CI가 없다.
13. `app.js`가 1300줄이다. 시트별·기능별 모듈 분리를 권장한다.
14. 서비스워커 캐시 버전(`sw.js`의 `CACHE`)을 배포마다 손으로 올려야 한다.
15. 로그인을 걷어내서 `auth.js`·`supabase/`가 미사용 상태다. Supabase 프로젝트 `yangseongi`(무료)와 Vercel의 `SUPABASE_*` 환경변수도 정리 대상.
16. 외부 의존: 카카오 우편번호 스크립트, Tesseract CDN, OSM/브이월드 타일. 오프라인에서는 OCR·지도 타일이 동작하지 않는다.
17. 대용량 `public/vendor/`(약 3MB)를 저장소에 직접 넣었다.

### 배포 작업 대기
18. 공식 주소 `yangseongi.land3lab.com` 연결 완료(사용자 확인). 브이월드 서비스 URL도 새 주소로 변경. `jrrsa-yangseongi.vercel.app` 접속은 `vercel.json` 리다이렉트(307)로 새 주소로 넘김.
19. 개발 세션의 네트워크 허용 목록에 비교 검토용 외부 사이트 1곳을 추가해 두었다(정리 필요).
