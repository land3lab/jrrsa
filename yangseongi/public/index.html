양성이는 법령 원문(국가법령정보센터)을 기준으로 계산한 사전 검토용 시뮬레이션입니다.
최종 판단은 관할 구청 건축과·건축위원회 심의와 건축사 현장조사에 따릅니다. · 법령 확인일

📖 사용설명서
3단계로 끝
  1. 주소를 넣거나 📎 대장 파일을 넣습니다
  2. 위반 여부가 확인 필요면 대장 첨부·위반 입력
  3. 4가지 결과 확인 → 🖨️ 검토표 인쇄
1. 시작하기

주소로: 도로명·지번 아무거나 입력 → 분석. 건축HUB 대장, 필지 경계, 용도지역, 건물 외곽선을 자동으로 가져옵니다.

대장 파일로: 검색창 옆 📎 → 사진·PDF 선택. 비밀번호 PDF는 비밀번호 칸이 뜹니다(정부24 발급본은 보통 발급 시 정한 번호).

지도에서: 🗺️ 지도에서 선택 → 건물을 누르면 그 필지를 조회합니다.

2. 결과 4가지 읽는 법

① 위반건축물 여부 — 대장의 '위반건축물' 표기와 위반 내역. 확인 필요는 아직 판단할 자료가 없다는 뜻입니다. 대장에서 표기를 못 찾았다고 위반이 없는 것은 아닙니다.

② 양성화 대상·가능 — 특정건축물 정리 특별조치법(2026.12.17 시행) 대상인지, 사용승인 기준을 통과하는지. 조건부 가능은 일부를 줄이거나 보완하면 가능하다는 뜻.

③ 전후 차이 — 대장(전) · 현황(위반 포함) · 양성화 후(권장안)의 건폐율·용적률·연면적·높이.

④ 전후 3D — 주황=위반, 초록=남기는 부분, 빨강 반투명=철거, 파란 면=일조 한계.

3. 대장 확인 · 값이 다를 때

수치(면적·층수)는 건축HUB 값을 우선, 위반 표기는 첨부 대장에서 읽습니다.

🏛️ 대장 정보 맨 위 출처 비교표에서 첨부 값(몇 쪽)·건축HUB 값·계산에 쓴 값을 나란히 볼 수 있고, 다르면 '차이'가 표시됩니다.

4. 위반 내역 입력

현장이 대장과 다르면 ✏️ 위반 내역에서 유형·위치·면적을 넣습니다.

  • 옥상 증축 — 용적률·높이·일조
  • 층 일부 / 수평 증축 — 건폐율·용적률
  • 발코니·필로티 — 용적률
  • 세대분할·용도변경 — 방화·피난·주차 기준 추가

현장을 봤는데 위반이 없으면 '현장 확인 — 위반 없음'을 누르세요.

5. 지도 · 직접 그리기

휴대폰: 한 손가락은 화면 스크롤, 두 손가락으로 지도 이동·확대. ＋ − ◎ ⛶(전체화면) 버튼도 있습니다.

자동 위치·모양이 틀리면 지도 위 막대에서 ✏️ 대지 경계 / 🏠 건물 외곽 / 📍 위반 위치를 고르고 지도를 눌러 점을 찍은 뒤 완료. 지도·3D·계산에 바로 반영됩니다.

6. 3D 보기

본문 3D를 누르거나 ④ 카드의 크게 보기. ↺ ↻ 돌리기, ⤒ ⤓ 기울이기, 3D·위·남측·동측·북측 시점, 전·후 나란히(두 모형이 같이 돌아감), ⛶ 전체화면.

건물 모양은 브이월드 실제 외곽선(없으면 필지 모양으로 추정), 증축·철거 부분은 단순화한 상자입니다.

7. 얼마나 남길 수 있나 (최소 보완)

📐 기준별 한도에서 기준마다 남길 수 있는 위반면적을 막대로 보여줍니다. 주황 카드가 가장 제한적인 기준이고, 위반면적에서 그만큼 뺀 것이 최소 보완(철거·감축) 규모입니다.

A. 특조법: 건폐율·용적률은 적용 배제, 규모 상한·일조가 한도. B. 건축법 추인: 조례 건폐율·용적률·일조를 모두 충족해야 합니다.

8. 확인·보완 · 검토표 인쇄

결과 아래 🔎 확인·보완 띠에 추가 자료가 필요한 항목 수가 나옵니다. 모아보기에서 항목별 바로가기와 다음 조치를 확인하세요.

🖨️ 검토표 인쇄 → 인쇄 창에서 'PDF로 저장'을 고르면 상담용 한 장 보고서가 만들어집니다.

9. 기록 · 설치 · 공개자료

💾 내 기록: 로그인 없이 이 기기에 저장·불러오기. 파일과 기록은 서버로 보내지 않습니다.

📱 설치: Chrome ⋮ → 앱 설치 / 아이폰 Safari 공유 → 홈 화면에 추가.

🗂️ 공개자료: 서초구 위반건축물 CSV를 불러와 주소를 대조합니다(조회 단서용).

자주 묻는 질문

Q. 건축물대장을 자동으로 발급하나요?
공식 발급은 정부24 본인인증이 필요해 자동화할 수 없습니다. 같은 내용은 건축HUB로 자동 조회하고, 발급받은 PDF를 넣으면 자동으로 읽습니다.

Q. 지도 위치가 틀려요.
주소 아래에 '위치 미확인/근사'가 있으면 🗺️ 지도에서 선택으로 건물을 누르거나 대지 경계를 그려 주세요.

Q. 수치가 대장과 달라요.
🏛️ 대장 정보 → 출처 비교표에서 어느 값이 쓰였는지 보고, 직접 고칠 수 있습니다.

Q. 결과를 그대로 믿어도 되나요?
사전 검토용입니다. 최종 판단은 관할 구청·건축위원회 심의와 건축사 현장조사로 정해집니다. 특조법 시행령은 아직 입법예고 단계입니다.
